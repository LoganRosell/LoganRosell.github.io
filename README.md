# Logan Rosell – Portfolio & Academic Website

Personal portfolio, data engineering projects, and quantitative research hosted via GitHub Pages: **[loganrosell.github.io](https://loganrosell.github.io)**.

Built with [Jekyll](https://jekyllrb.com/) using the [AcademicPages](https://academicpages.github.io/) template, styled with Markdown, and rendered with KaTeX.

---

## Featured Projects

* **[Pedestrian Fatalities in Vision Zero US Cities](https://loganrosell.github.io/portfolio/pedestrian-fatalities/)**
  * End-to-end data pipeline and multi-panel Grafana dashboard analyzing 7,538 fatal crashes across 61 US cities (2018–2023).
  * Integrates NHTSA FARS, US Census ACS APIs, and Open-Meteo weather records into a cloud PostgreSQL star schema on Railway.
  * **Stack:** Python, PostgreSQL, SQL, Railway, Grafana

* **[Regional and Temporal Variation in Coal Power's Emission Intensity](https://loganrosell.github.io/portfolio/)**
  * Global statistical evaluation (2000–2024) analyzing carbon intensity ($$ \text{mtCO}_2/\text{TWh} $$) trends across regions using Ember energy data.
  * Implemented non-parametric testing and regional linear regression models to assess efficiency gains versus capacity phase-out.
  * **Stack:** R, Statistical Modeling, KaTeX
